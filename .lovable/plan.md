# Качество первого бесплатного декода

Один слабый ответ = потерянный пользователь навсегда. Сейчас нет ни одного механизма, который бы это ловил. Делаем только это.

## Что меняем

- Планка качества в промпте: запрет на общие советы («поговорите открыто», «сохраняйте спокойствие»), обязательная цитата из исходного сообщения в разборе, обязательный конкретный приём из библиотеки тактик.
- Проверка результата перед выдачей: минимальная длина, наличие цитаты и тактики. Если модель выдала пустышку — один автоматический повтор с более жёстким требованием, а не показ слабого результата.
- Отказ вместо халтуры: если во входящем тексте манипуляции реально нет, честно писать «здесь чисто» и не выдумывать тактику.
- Три варианта ответа везде, где сейчас меньше — выше шанс, что хотя бы один попадёт.
- Обратная связь одним кликом под отчётом: «в точку / мимо», чтобы видеть, на каких типах сообщений модель проваливается.

## Техническая часть

- `src/lib/analyze.server.ts`: ужесточённый system-промпт (бан банальностей, обязательная цитата, обязательная тактика из `src/lib/tactics.ts`), валидация ответа модели + один retry, ветка «манипуляций не обнаружено», гарантия трёх вариантов ответа.
- `src/lib/scan-types.ts`: поле для случая «чисто», чтобы фронт мог отрисовать честный отказ.
- `src/components/cyber/states.tsx`: отображение варианта «здесь чисто» и кнопки обратной связи в `UnlockedState`.
- Хранение обратной связи: новая таблица `scan_feedback` (RLS + GRANT) и серверная функция записи в `src/lib/scan.functions.ts`.
